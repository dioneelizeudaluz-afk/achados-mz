# Achados MZ

Plataforma de recuperacao de documentos perdidos em Mocambique.

## Funcionalidades

- Procurar documentos encontrados
- Registar documento encontrado
- Comunicar documento perdido
- Painel administrativo
- Sistema de correspondencias

## Tecnologias

- React + Vite
- Supabase
- Tailwind CSS
- PWA

## Configuracao

1. Crie projeto no Supabase
2. Execute o schema.sql
3. Configure .env
4. npm install
5. npm run dev

## Deploy

O projeto esta pronto para deploy na Vercel.
